# The Confident Clinician SEO Launch Checklist

The site code is search-ready. These remaining tasks require access to Tiffany's domain, Google, Bing, or analytics accounts.

## Search engine setup

- [ ] Create a Google Search Console **Domain property** for `theconfidentclinician.me` and add the DNS verification record.
- [ ] Submit `https://theconfidentclinician.me/sitemap.xml` in Search Console.
- [ ] Inspect and request indexing for `/`, `/about`, `/clinical-confidence-lab`, `/resources`, and each resource article after the production deployment.
- [ ] Create Bing Webmaster Tools access, import the verified Search Console property, and submit the same sitemap.
- [ ] Check Search Console's Page indexing, Core Web Vitals, HTTPS, and Enhancements reports after Google has recrawled the site.

## Measurement setup

- [ ] Create or confirm a GA4 property and record its Measurement ID (`G-XXXXXXXXXX`).
- [ ] Decide whether to use Google Analytics directly or through Google Tag Manager.
- [ ] Add a privacy/consent solution appropriate for the visitor locations served before enabling nonessential analytics.
- [ ] Track meaningful conversions: waitlist modal opened, waitlist submitted, Lab page viewed, guidebook signup submitted, and outbound Movement Library clicks.
- [ ] Connect Search Console to GA4 after both properties are verified.

## Trust and entity signals

- [ ] Keep Tiffany's credentials, author name, professional scope statement, privacy policy, and contact route current.
- [ ] Add stable public profile URLs to the Person/Organization `sameAs` data when available.
- [ ] Confirm the social-share image and business name display correctly in Facebook Sharing Debugger and LinkedIn Post Inspector.

## Ongoing search growth

- [ ] Publish one genuinely useful resource at a sustainable pace; prioritize specific questions newer therapists search for.
- [ ] Link each new resource to the most relevant existing resource and to the Lab only where it naturally helps the reader.
- [ ] Review Search Console monthly for queries, pages with impressions but low click-through rate, indexing problems, and new topic opportunities.
- [ ] Refresh articles when professional guidance, terminology, or the Lab offering changes; update `dateModified` when the content changes materially.
- [ ] Avoid buying links, keyword stuffing, mass-produced thin articles, or claiming guaranteed rankings.
